# Git esitamise soovitus

Ära lisa repositooriumisse `.env`, `node_modules`, `dist` ega `data/*.db*` faile.
Lisa sisulised commit'id eraldi tööosade kaupa, näiteks:
1. `feat: guided discovery and project persistence`
2. `feat: backlog editing and definition of ready`
3. `feat: structured mockups and refinement versioning`
4. `feat: AI grooming proposals and approval workflow`
5. `docs: add usage scenario and project backlog`

Need on soovituslikud commit-sõnumid; need tuleb luua sinu kohalikus Git-repositooriumis.
